# Development scripts examples

The scripts in this directory were used for testing during the development of the SDT Dask tool.
We provide them here as a reference for anyone that might find them useful to reuse or develop their
own scripts to run the tool.

> **Note:** `rev_far_pvdb_dask.py` is **archival only** and will not execute. It depended on
> `PVDBPlug` (removed from `sdt_dask/dataplugs/`), which relied on the deprecated `dataio` module
> that was removed from Solar Data Tools in version 2.0. The script is retained for reference.
