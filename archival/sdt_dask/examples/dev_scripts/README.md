# Archival Development Scripts

`rev_far_pvdb_dask.py` is **archival only** and will not execute. It depended on
`PVDBPlug` (removed from `sdt_dask/dataplugs/`), which relied on the deprecated
`dataio` module that was removed from Solar Data Tools in version 2.0. The script
is retained for reference.

The still-usable development script examples live in the top-level
`sdt_dask/examples/dev_scripts/` directory.
